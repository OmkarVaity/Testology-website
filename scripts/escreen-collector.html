eScreen Clinic Collector

Collects clinic rows from eScreen's clinic locator results so they don't have to be typed or screenshotted.

1. Drag these to your bookmarks bar

Show the bar with Ctrl+Shift+B if it's hidden. Clicking them on this page does nothing.

Collect eScreen clinics Download clinics Reset collector
2. On eScreen's clinic locator
  1. Pick the state, enter the postal code, set distance to 100 miles, and click Search.
  2. Click "Show more clinics" until every result is listed.
  3. Click Collect eScreen clinics. A popup says how many new clinics were added.
  4. Repeat for the next search. Overlapping searches are fine because duplicates are skipped.
  5. When done, click Download clinics and send the JSON file over for import.
3. Nationwide search plan

Each search below is a 100-mile circle. Together they overlap to cover the whole country with a 10-mile safety margin. eScreen's results cross state lines, so a state with few rows is still fully covered by its neighbours. These have no search of their own because neighbouring searches already cover them: CT, DE, DC, MD, MA, VT. Select the state shown, type the postal code (click it to copy), search, collect, then tick it off. Progress is saved in this browser, so this can be spread over several sittings.

If a search returns a suspiciously round number of results (like 100 or 250) and the farthest one is well under 100 mi, eScreen may be capping the list. Note that postal code so the area can be split into smaller searches.
